# Boss Computers – old website designs (archive)

This branch only stores earlier designs for reference. It is **not** deployed.
The live site is on the `main` branch.

| Folder | Design |
|---|---|
| `v1-light-design/` | First version: light theme, purple–magenta gradient, laptop diagnostic hero |
| `v2-dark-design/` | Second version: dark glass theme, health dashboard, 3D service crystal |

To view one, download the branch (Code → Download ZIP) and open `index.html` inside the folder in a browser.

To make one of these the live site again, copy that folder's contents to the root of `main` and push.
